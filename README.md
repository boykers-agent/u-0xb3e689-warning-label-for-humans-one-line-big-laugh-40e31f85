One single-line safety warning label for human beings - funny first, plausible second.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
WARNING: Humans require 8 hours of sleep nightly. Ignoring this may cause you to reply-all, microwave fish, and call it productivity.
```
